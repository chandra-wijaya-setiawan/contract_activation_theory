# v1.7 Phase A.1 — Corpus + LIBRARIAN (advisory) (DONE 2026-05-30)

## What

Wires the offline simulator into runtime as a lightweight advisor. The
LIBRARIAN reads the SQLite corpus, refreshes its predicate tree, computes
d*(s) via backward Dijkstra, and recommends the lowest-score action.
The activator injects this as a transient `[CORPUS HINT]` system message
in the performer's context. **The LLM still picks.** Math doesn't force
the choice — that's Phase A.2.

## Components shipped

- **`cat/state_class.py`** — shared canonicalization (Sample,
  PredicateTree, action_intent, abstract counters, `_FeatureState`)
- **`cat/corpus.py`** — SQLite (trajectory + sample tables); dedup on
  trace_id; computes `realized_cost_to_goal` per sample
- **`cat/librarian.py`** — runtime query: `recommend(raw_features) →
  Optional[Recommendation]`. Returns None on cold/disconnected states
  (implicit DEFER).
- **`cat/activator.py`** — optional `librarian=` kwarg; `_librarian_hint()`
  builds transient system message from current trace events
- **`cat/tb_agents.py`** — constructs Librarian when `CAT_CORPUS_DB` env
  var is set; safe cold-start if path missing/empty
- **`scripts/seed_corpus.py`** — bulk ingest from existing run dirs
- **`scripts/run_bench.sh`** — post-run writeback after each run

## Initial corpus

25 trajectories, 540 samples (after smoke writeback). Sources: swe10-v1.7-tools,
swe10-v1.6.6-final, smoke-tighten-v2.

## Smoke test (3 tasks)

| Task | v1.7-tools baseline | A.1 (with Librarian) | Δ tokens |
|---|---|---|---|
| pytest-6202 | PASS, 28K | PASS, 32K | +14% (hint overhead on small task) |
| django-12039 | PASS, 445K | PASS, 365K | **−18%** (−80K) |
| django-13315 | FAIL, 489K | FAIL, 368K | **−25%** (−121K) |

Same solve rate, significant token savings on bigger tasks. Hint IS
visible to the LLM but math doesn't FORCE the choice.
