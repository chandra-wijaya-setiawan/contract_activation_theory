# v1.7.0 — Offline simulation: CEGAR + Dijkstra (DONE 2026-05-30)

> See also `docs/dijsktralayer_manual_by_hand_draft.md` — 12-section
> walkthrough with real data from a single trace through the full pipeline.

## What

External research (TriCEGAR mechanism + Ferns/Precup criterion + Dijkstra
objective) reframed v1.7 around three layers:

- **Mechanism — CEGAR predicate tree.** Raw features stay UNHASHED; the
  tree applies a function over them. Starts maximally coarse (one leaf
  per obligation); splits earn into the tree via counterexamples.
- **Criterion — value bisimulation.** Trigger B: leaf with highest CV of
  realized cost-to-goal violates Ferns/Precup; split it. Decision-tree
  stump picks the predicate (hand-rolled, no sklearn).
- **Objective — backward Dijkstra.** Compute d*(s) per leaf from a virtual
  GOAL sink (0-cost edge from terminal state of every PASS trajectory).

## Two-tier feature design

- **Domain-agnostic core**: `obligation_hash`, `plan_idx`, `last_outcome`,
  `durable_change_count`, `iter_since_durable_change`,
  `verify_attempt_count`, `investigate_attempt_count`, `mutate_attempt_count`,
  `last_action_intent`, `n_unique_actions`, `n_unique_errors`,
  `attempted_actions`
- **Domain-specific (code-Python)**: `last_tool`, `last_bash_class`,
  `env_facts`, `attempted_bash_classes`
- `action_intent ∈ {investigate, mutate, verify, other}` — declared per
  Capability (currently hardcoded for SWE-bench tools)

## Validated on merged swe10 corpus (19 traces, 392 samples)

- 38 leaves after CEGAR refinement (was 10 coarse leaves at start)
- **22 of 30 splits domain-agnostic** (73%) — `verify_attempt_count`,
  `iter_since_durable_change`, `durable_change_count`
- d* values now meaningful (range 0–285K tokens, not all zero like v1)
- Predicates picked match human-predicted failure modes (pytest-loop,
  drift signals, post-edit state)
