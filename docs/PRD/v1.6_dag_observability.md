# v1.6 — DAG-first observability + terminology alignment (DONE 2026-05-28)

> See also `docs/1.6.2.9_PRD_renaming_and_dijkstra.md` for the canonical
> terminology rename decision record.

## Goal

Promote the trace from flat event stream to typed reasoning DAG.

## What shipped

- **`parent_id` discipline audit**: every non-root event has a direct
  causal parent
- **`cat/dag.py`**: RunDAG class with `longest_chain` / `branch_points` /
  `path_to` queries
- **`cat/dag_svg.py`**: inline SVG visualizer (no external graphviz)
- **HTML KPI report** (`cat/run_report.py`): DAG SVG + reasoning trace +
  cost-by-layer + cross-run INDEX
- **Structured run output layout**: `data/runs/<bench>/<date>/<time>-<runid>/`
- **`scripts/run_bench.sh`** launcher with manifest.json + auto-report

## Terminology rename (per PRD 1.6.2.9)

- role tags: `planner` → `stipulator`, `executor` → `performer`,
  `judge` → `attestor`
- methods: `_decompose` → `_stipulate`, `_invoke_once` → `_perform_once`
- event kinds: `contract_decompose` → `contract_stipulate`,
  `capability_invoke` → `capability_perform`
- step names: DECOMPOSE → STIPULATE, INVOKE → PERFORM, CLOSE → DISCHARGE
- backward-compat aliases preserved in `cat/dag.py` event-kind map
